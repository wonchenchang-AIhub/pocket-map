# 口袋地圖

公開的台灣美食、景點、住宿與伴手禮收藏網站。純 HTML、CSS、JavaScript，可使用 GitHub Pages 發布。

## 功能

- 關鍵字搜尋、縣市與類型篩選、來源評分與評論數排序。
- Google 地圖搜尋嵌入與原始地點連結；不使用推估座標。
- 按目前篩選條件隨機挑選下一站。
- 裝置本機想去清單，無登入、無跨裝置同步。
- 手機與桌面版面、鍵盤操作與可關閉的詳情視窗。

## 資料

`places.json` 由使用者提供的「地圖收藏清冊.html」資料陣列解析而來，未執行原檔程式。排除生活服務與其他（僅地址）後保留 319 筆。中英文名稱、數字與描述保留原始值。

原檔標示查詢日 2026-10-01，本站未獨立驗證評分、評論數、營業時間、價格或描述。Google 地圖嵌入按名稱與區域搜尋，可能存在同名誤配，原始 Google 地圖連結供使用者核對。

## 維護

編輯 `places.json` 更新地點；修改 `style.css` 調整外觀；修改 `app.js` 調整互動。請避免公開私人地址與敏感收藏。

本機可用任何靜態 HTTP 伺服器預覽，直接以 file:// 開啟時瀏覽器可能阻擋 JSON 載入。

## 發布

GitHub Pages 設定使用 `main` 分支根目錄。無需付費地圖金鑰與建置流程。

# 口袋地圖

公開的台灣餐飲、景點與住宿收藏網站。純 HTML、CSS、JavaScript，可使用 GitHub Pages 發布。

## 功能

- 關鍵字搜尋、縣市與類型篩選、來源評分與評論數排序。
- Google 地圖搜尋嵌入與原始地點連結；不使用推估座標。
- 按目前篩選條件隨機挑選下一站。
- 裝置本機想去清單，無登入、無跨裝置同步。
- 手機與桌面版面、鍵盤操作與可關閉的詳情視窗。

## 資料

`places.json` 由使用者提供的清冊資料陣列解析而來，未執行原檔程式。只保留餐飲、景點與住宿類，2026-10-13 清理後為 310 筆。中英文名稱、數字與描述保留原始值。

原檔標示查詢日 2026-10-01，本站未獨立驗證評分、評論數、營業時間、價格或描述。Google 地圖嵌入按名稱與區域搜尋，可能存在同名誤配，原始 Google 地圖連結供使用者核對。

## 維護

更新地點請執行 `node scripts/update-data.cjs "外部原始清冊.html"`（也支援 JSON）。程式會自動過濾並同步更新 `places.json` 與公開 HTML 清冊。不要將未過濾的原始收藏放入公開儲存庫。工作區 `private-imports/` 已忽略，亦可直接讀取下載資料夾的原檔。

分類允許清單放在 `privacy-policy.js`：在地小吃、中式台菜、日韓料理、異國料理、火鍋燒烤居酒屋、咖啡甜點冰品、景點步道、住宿露營。其他類別與不明類別全部排除；國華中醫藥器材行亦持續排除，即使日後被錯誤歸入允許分類。額外資料欄位不匯入。

執行 `node scripts/verify-data.cjs` 檢查兩份公開資料。發布流程每次先自動過濾再驗證，只上傳必要網站檔案；網頁載入也使用相同過濾規則。此規則依來源分類判斷，不會自動辨識描述中所有個人資訊，請勿加入私人備註。

本機可用任何靜態 HTTP 伺服器預覽，直接以 file:// 開啟時瀏覽器可能阻擋 JSON 載入。

## 發布

GitHub Pages 使用 GitHub Actions，自 `main` 更新時自動清理、驗證並發布。無需付費地圖金鑰。
